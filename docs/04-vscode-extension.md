# VS Code Extension

В репозитории есть папка `vscode-penlang/` с заготовкой расширения для `.vcl`.

## Что уже есть

- регистрация языка
- TextMate-подсветка
- snippets
- базовые подсказки
- hover по функциям и переменным
- signature help с типами параметров и возвращаемым типом
- completion для функций текущего файла, импортированных модулей и stdlib

## Локальный запуск

```bash
cd vscode-penlang
npm install
```

Открыть папку расширения в VS Code и нажать `F5` (Run Extension).

## Что умеет подсветка сейчас

- при наведении на `fn` или вызов функции показывает сигнатуру
- при наборе `(` и `,` показывает активный параметр
- для встроенных функций и `net.*` показывает типы аргументов и результата
- для функций из текущего файла тоже показывает сигнатуру, если она объявлена как `fn`
- для `use "libtest.vcl"` подсказывает `libtest.sum(...)`
- после точки подсказывает только члены модуля, даже если имя уже частично набрано

## Замечание

Расширение осталось совместимым с текущим синтаксисом Vexcore, но это отдельный tooling-пакет. Рантайм языка находится в Rust workspace и не зависит от VS Code-части.
