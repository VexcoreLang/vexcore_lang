# VS Code Extension

В репозитории есть папка `vscode-penlang/` с заготовкой расширения для `.vcl`.

## Что уже есть

- регистрация языка
- TextMate-подсветка синтаксиса
- snippets для быстрого ввода кода
- автодополнение для встроенных функций и модулей
- hover информация с сигнатурами функций
- signature help с типами параметров и возвращаемым типом
- completion для функций текущего файла, импортированных модулей и stdlib (`net`, `udp`)
- поддержка пользовательских модулей через `use "file.vcl"`

## Поддерживаемые встроенные модули

### `net` - работа с сетевыми операциями

- `net.ping(host: str): bool` — проверка доступности хоста
- `net.port_open(host: str, port: int): bool` — проверка открытости TCP порта
- `net.resolve(hostname: str): str | null` — разрешение IP адреса хоста

### `udp` - работа с UDP

- `udp.test(): bool` — тестирование функциональности UDP модуля

## Локальный запуск

```bash
cd vscode-penlang
npm install
```

Открыть папку расширения в VS Code и нажать `F5` (Run Extension).

## Что умеет подсветка сейчас

- при наведении на `fn` или вызов функции показывает сигнатуру
- при наборе `(` и `,` показывает активный параметр
- для встроенных функций и stdlib (`net`, `udp`) показывает типы аргументов и результата
- для функций из текущего файла тоже показывает сигнатуру, если она объявлена как `fn`
- для `use "libtest.vcl"` подсказывает `libtest.sum(...)`
- после точки подсказывает только члены модуля, даже если имя уже частично набрано

## Установка расширения

Расширение доступно в папке `vscode-penlang/` проекта.

### Установка в развивающемся режиме

```bash
cd vscode-penlang
npm install
```

Затем открыть папку расширения в VS Code и нажать `F5` (Run Extension) — откроется новое окно VS Code с активированным расширением.

### Установка как постоянное расширение

```bash
# Скопировать в папку расширений VS Code
cp -r vscode-penlang ~/.vscode/extensions/vexcore.penlang-tools-0.3.0

# Или использовать команду VS Code
code --install-extension /path/to/vexcore_lang/vscode-penlang
```

После установки расширение будет автоматически активировано для файлов с расширением `.vcl`.

## Замечание

Расширение осталось совместимым с текущим синтаксисом Vexcore, но это отдельный tooling-пакет. Рантайм языка находится в Rust workspace и не зависит от VS Code-части.
