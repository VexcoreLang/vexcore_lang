# Language Reference

## Секции

- `[setts]` - настройки окружения исполнения (опционально)
- `[scenary]` - основной код (обязательно)

## Типы

- `int`: `1`
- `float`: `3.14`
- `str`: `"hello"`
- `bool`: `true`, `false`
- `null`: `null`
- `list`: `[1, 2, 3]`
- `json`: `{"key": 1}`

## Мягкая типизация

Типы опциональны и задаются аннотациями:

```pen
let port: int = "8080";   # будет приведено к int
let host: str = 127001;    # будет приведено к строке
```

Если значение нельзя привести к типу, будет runtime-ошибка.

## Импорт файлов

```pen
use "lib.vcl";
```

Поддерживаются пути с расширением `.vcl` и `.vcl`.

## Пользовательские функции

```pen
fn sum(a: int, b: int): int {
  return a + b;
}

let x = sum(40, 2);
log(x);
```

`return;` без значения возвращает `null`.

## Базовые конструкции

- Арифметика: `+ - * / // % **`
- Сравнение: `== != < > <= >=`
- Логика: `&& || !`
- Диапазон: `1..10`
- Присваивание: `= += -= *= /=`

## Вызовы модулей

```pen
let ok = net.ping("8.8.8.8");
let ip = net.resolve("example.com");
```
